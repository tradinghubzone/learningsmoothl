# StudyBridge – Abroad Student Task Booking

A clean, responsive single‑page website where international students can book academic tasks (essays, math, programming, etc.) starting from **$10**. Bookings are sent directly to your WhatsApp.

![StudyBridge preview](https://via.placeholder.com/1200x600?text=StudyBridge+Preview) <!-- optional: replace with real screenshot -->

## ✨ Features

- **Responsive UI** – works on mobile, tablet, and desktop.
- **Task catalog** – displays 6 most common student tasks with fixed affordable prices ($12–$25).
- **Interactive booking form** – student enters name, selects a task (price updates automatically), optional deadline.
- **WhatsApp integration** – on “Book via WhatsApp”, a pre‑filled message with all booking details opens in WhatsApp, addressed to **0788245106**.
- **Price display** – dynamic total price based on selected task.
- **Clean design** – modern, gradient background, rounded cards, smooth hover effects.
- **No backend required** – pure HTML/CSS/JS, works as a static file.

## 🛠 Tech Stack

- **HTML5** – semantic structure
- **CSS3** – custom properties, flexbox, grid, responsive media queries
- **Vanilla JavaScript** – form handling, dynamic price update, WhatsApp deep link
- **Font Awesome 6** (CDN) – icons
- **Google Fonts** (Inter) – typography
